Descripción:
iCaseStore es una aplicación web de comercio electrónico desarrollada con React que permite a los usuarios explorar un catálogo de fundas para iPhone, ver detalles de cada producto y gestionar un carrito de compras. El proyecto fue desarrollado como parte de un curso de React y cumple con todos los requisitos solicitados.

Características principales:

° Catálogo de productos con 6 fundas diferentes.

° Vista de detalle de cada producto.

° Carrito de compras con gestión de cantidades.

° Persistencia del carrito en localStorage.

° Diseño responsive y moderno.
